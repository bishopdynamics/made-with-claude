# Self-hosted fonts

Original, unmodified WOFF2 files and licenses from Inter v4.1 and JetBrains Mono v2.304. Both families use the SIL Open Font License 1.1; the complete upstream licenses are retained beside these assets.

Inter supplies variable upright and real italic faces. JetBrains Mono supplies regular and real italic faces for code, including italic syntax tokens. Only the upright Inter face is preloaded; other faces load when used. No runtime font provider is involved.
